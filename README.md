# locbench — 定位算法测试 / 调参（纯数值模拟）

对声发射震源定位算法做**合成数据**测试与参数调优的实验层。
所有数据均为数值模拟：传感器阵列、震源、到时全部由模拟生成
（到时误差、采样率量化、丢道均可注入），真值已知，误差可直接统计。

## 功能

- **合成场景**：三维/二维试样（默认 100×100×200 mm）；传感器布置
  支持几何特征（横边/纵边/垂边/侧面/正面/顶面/顶点，可任意组合）、
  随机整数坐标、自定义文本、压头布置（折射场景用：试样盒六面外
  各布 n 个传感器）；震源随机或按间距网格布置；
- **波速模型**：均质直线传播，或折射双层（试样 v₁ + 已知压头 v₂，
  Snell 折射正演——aelib `RefractionLocator` 的适用场景）；
- **定位算法**：Geiger（均质直线模型），或折射路径（locRP，
  Rui et al. 2024：联合反演震源与 v₁，LM + 迭代鲁棒加权）；
- **误差模拟**：到时误差 σ、采样率量化、逐通道丢道概率；
- **定位试验**：逐试验误差/收敛/迭代/耗时统计（中位、均值、p95），
  等轴 3D/2D 定位结果图与误差分布直方图；
- **参数敏感性**：对定位器参数或场景参数做单参数扫描（取值支持
  等间距简写，如 `2600:8000:300`），误差曲线 + 耗时曲线。

## 安装

```bash
pip install git+https://github.com/glassyskyabove/locbench.git
```

适用 aelib 版本：**≥ 0.9.41**（折射定位器自 aelib 0.9.41 引入）。

## 启动

```bash
locbench
```
